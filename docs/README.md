# docs/ — Portfolio Feature Guides

Technical reference guides for specific features of this portfolio.
Written for agents and developers making code changes.

## For agents

Read `docs/index.json` first — it lists every guide with tags, keywords, and the files each guide affects.
Load only the guide(s) relevant to your task.

## Conventions

- File paths are relative to project root unless noted.
- JSON examples include all fields so they can be copied as templates.
- Each guide covers one feature end-to-end: schema → component → usage steps.
